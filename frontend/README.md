# NutriPulse Frontend

React SPA built with Vite, Tailwind CSS, TanStack Query, and Zustand.

## Commands
- `npm run dev`: Launch Vite local dev server on port 5173.
- `npm run build`: Production build into `dist/`.
- `npm run preview`: Preview production build locally.

## Features
- Three-Mode Theme System (Light / Dark / System Default) with zero initial flash.
- Debounced food search with live nutrition facts scaling.
- Comprehensive food diary with multi-date navigation.
- Interactive Recharts for calories, macros, weight, and water.
- Fully accessible keyboard navigation and mobile-responsive layout.
